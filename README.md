# DigiTools
  DigiTools is a modern, high-performance web application designed for creators and businesses to explore and purchase premium digital assets. Inspired by Programming Hero designs, it features a seamless user experience, a dynamic cart     system, and a fully responsive interface.
#
#
## Technology Used
## . React.js
## . Tailwind CSS
## . React-Toastify
## . JSON Data
## . daisyUI
## . JavaScript (ES6+)
#
#
## Features
## Smart Cart Management:
   Allows users to add items to a cart with duplicate prevention and real-time toast notifications

## Instant Toast Notifications:
   Provides real-time visual feedback using React-Toastify when items are successfully added to the cart or when a duplicate is prevented.

## Conditional View Toggle:
   A clean navigation system that switches between the product landing page and the cart view without page reloads.
